RAG Pipeline Dashboard

Ingest → Preprocess → Rules → Embed → Ask — all in one place, no external tools required.

0 Configuration not set

Optional — if you already set env vars on the server (EMBEDDING_API_KEY / EMBEDDING_MODEL / LLM_API_KEY / LLM_MODEL), this is pre-filled. Override here if you want to change models without redeploying.

1 Ingest a file

.csv · .xls / .xlsx · .json · .md · .pdf

2 Preprocess optional

Filter rows and/or remove duplicates before running rules or embedding.

3 Apply rules optional

JSON list of rule objects: {"name","condition","action"}. Runs vectorized via df.query() or numpy.select.

  


  
  

    
4 Generate embeddings

    
Embeds the ingested/processed text column via your configured embedding model.

    
    

  


  
  

    
5 Ask a question

    
Retrieves top-k relevant chunks, compresses them, and answers using your configured LLM.
